# Python Pygmae Aim Trainer
A simple mouse aim trainer using pygame


## Getting Started

Follow these steps to run the project locally using a virtual environment.

### 1. Clone the repository

```bash
git clone https://github.com/peaush07/aim-trainer.git
cd Aim-trainer
```


### 2. Set Up Venv

```bash
python -m venv env
```
(This is for Mac and Linux)
```bash
source ./env/bin/activate 
```
(This is for Windows)
```bash
source ./env/Scripts/activate 
```

### 3. Install Pakage

```bash
pip install pygame
```

### 4. Run file

```bash
python main.py
```
